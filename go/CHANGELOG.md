# Changelog

All notable user-facing changes to Flyrail for Go. Package versions are independent from
configuration bundle labels and shared format schema versions.

## [Unreleased]


### Features

- Add Go module with no-cgo macOS ACL and exclusive-rename primitives
- Add Go semantic values, strict JSON, Unicode keys and OS error text
- Load Go bundles from directories, ZIP archives, fs.FS and memory
- Load schema-2 Go bundles with artifacts, assets and dependencies
- Add the Go hook protocol and embedded hook runtime
- Add Go targets, destinations and pure rendering
- Add Go claims, ownership types and the state record codec
- Add the Go document editor core and section editing
- Add Go JSON and JSONC document editing
- Add the lossless Go TOML scanner
- Add Go TOML and schema editing with the editing differential
- Add Go native security capture, privacy checks and canonicalization
- Add Go directory and memory state stores and resource authority
- Add Go resource admission, planning and resource I/O
- Add the Go transaction protocol and crash recovery
- Add the Go configuration lifecycle API
- Add the Go skills API, inspection, agent discovery and plan summaries
- Add the Go interop driver and cross-language transaction checks
- Add the Go notes and checksum example CLIs and package QA
